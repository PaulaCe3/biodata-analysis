# BioData Assistant

Aplicación de Data Science para explorar, validar y modelar datasets biológicos tabulares.

## Estado del proyecto

🚧 Proyecto en desarrollo.

## Objetivo

Construir una aplicación que permita:

- Cargar un dataset biológico en formato CSV.
- Reconocer la estructura y los tipos de variables.
- Detectar problemas de calidad de datos.
- Realizar un análisis exploratorio de datos.
- Entrenar modelos básicos de clasificación o regresión.
- Evaluar los modelos correctamente.
- Explicar los resultados de forma clara mediante inteligencia artificial.

## Tecnologías previstas

- Python
- pandas
- NumPy
- matplotlib
- scikit-learn
- Streamlit
- Git y GitHub
